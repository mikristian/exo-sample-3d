001WHY WE'RE BUILDING

Great ideas shouldn't stop at the software barrier.

Designers should be able to explore, test, and learn without committing to expensive software before they make their first pattern. Open tools give more people a place to start.

ClothCraft brings pattern drafting and 3D exploration into a growing workspace, with source code that can be studied and improved. The mission is ambitious; the work is still underway.

005 / OUR WORKING PRINCIPLES

Why transparent development matters.

A fashion tool has to earn trust through reproducible results, especially when fabric cutting, manufacturing cost and physical fit are involved.

01 / CLOTHCRAFT

Accessible tools

Open source lowers barriers to understanding and changing the software. Users still need appropriate computers, training, samples and process verification.

02 / CLOTHCRAFT

Honest demonstrations

Screen recordings show genuine work in the application. They are not evidence that simulation or production exports match a certified industrial benchmark.

03 / CLOTHCRAFT

Test what is produced

The project needs physical pattern samples, manufacturing files, traceable measurements and independent receiving results.

04 / CLOTHCRAFT

Respect contributor ownership

Never upload confidential brand patterns, unlicensed artwork, private customer measurements or proprietary factory files without authorization.

05 / CLOTHCRAFT

Explain the gaps

Publish what a test actually checked, what failed, and what has not yet been validated. Avoid made-up software completion percentages.

06 / CLOTHCRAFT

Share useful improvements

Bring precise bug reproduction, tutorials, accessibility feedback, test files, code review and user research.

006 / WHAT COMES NEXT

An open invitation, not an empty promise.

We want the community to influence priorities by sharing the difficult, specific examples that reveal whether the workflow is truly reliable.

01 / CLOTHCRAFT

Designers — send the hard cases

Complex construction, multiple materials, unique shapes and graded pieces expose problems quickly.

02 / CLOTHCRAFT

Factories — explain the receiving process

Tell us what cutting files, documentation, layer conventions and tolerances you can actually accept.

03 / CLOTHCRAFT

Developers — test the boundaries

Help create geometry adversarial tests, performance benchmarks and native desktop stability checks.
