02 / VALIDATION GATES

What a higher percentage must mean.

Growing code coverage is useful, but professional garment CAD demands external evidence. These milestones are deliberately not shown as percentages until defensible acceptance criteria and measured results exist.

A / GEOMETRY

Reliable geometry

Round-trip source files, verify units, curves, topology, cutting contours, seams and notches across all affected sizes; reject edited or incomplete return files.

B / PHYSICAL

Fabric and fit correlation

Compare physical swatches and garment samples against controlled virtual tests for repeatability, error bounds, collision and drape.

C / INDUSTRIAL

Independent receiving

Require an unaffiliated receiver or factory to reopen actual exports and report acceptance with explicit tolerances and documented exceptions.

03 / FROM A TEST TO REAL PROOF

What would make the next
milestone credible?

The project tracks presence-based checkpoints and open engineering work, but a higher count alone never proves industry-level capability. Each system has a different practical acceptance path.

01 / 2D & GRADING

Original file fidelity

Gather documented size sets, seam relationships, curves, notches and accepted tolerances. Repeat saved-source and export/receive comparisons across all relevant sizes.

02 / 3D & PHYSICS

Physical correlation

Use measured fabric properties, controlled avatar dimensions and real garment samples. Record repeatability and failure cases, not just attractive renders.

03 / IMPORT & EXPORT

Independent read-back

Test malformed files, changed byte sequences, unit mismatches, unsupported entities and receiving failure evidence.

04 / USER INTERFACE

Real design sessions

Measure selection, edit, zoom, scroll, save and recovery performance during extended projects on supported desktop hardware.

05 / TECHNICAL PACKS

Connected documents

Validate that flats, BOM, measurements, comments and pattern versions agree and can be reopened without loss.

06 / RELEASES

Trustworthy distribution

Check app startup, crash handling, package integrity, signatures where applicable, actual download artifacts and realistic system requirements.
