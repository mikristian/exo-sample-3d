Help & Support ↗

Installation and access

Is ClothCraft free? +

The project is open source and provides development downloads where published. Check the repository license and the actual release before installing.

Which computer do I need? +

The demonstrated desktop distribution is focused on macOS Apple Silicon. Other platforms and packages may have different support levels; inspect release notes.

Where is the download? +

Use the Download page for the current experimental build and release evidence. Avoid unverifiable third-party installers.

Is the project ready for manufacturing? +

No blanket manufacturing-readiness claim is made. Verify contours, units, grading, cutting file layers and physical samples independently.

Design and geometry

Can I import Illustrator, PDF, DXF, SVG or 3D files? +

Interchange work is under development. Individual formats have different semantics and may import partially. Check current features and round-trip files.

Can I edit patterns and technical flats? +

The project has demonstrated editable 2D geometry and vector workflows; linked constraints and every-size grading need further validation.

Does ClothCraft provide accurate 3D fitting? +

The garment viewport and solver are experimental; render quality is not physical-fit certification. Use physical samples and calibrated fabric measurements.

Can I grade patterns between sizes? +

Grading functionality is being developed. Before production, verify every size against grading rules, seams and points of measure.

Community and contribution

Where can I propose a feature? +

Use the Ideas Board. A public idea opens a GitHub issue for review and authenticated submission.

Are Marketplace forum discussions publicly shared? +

The current forum interface saves threads, replies and votes in your browser only. It is not a shared public backend.

Can I donate pattern data or a tech pack? +

Propose rights-cleared example files through the contribution process. Do not upload confidential customer designs or proprietary factory files.

How can developers help? +

Contribute reproducible tests, native Rust and geometry work, interoperability, documentation, desktop reliability audits and profiling.
