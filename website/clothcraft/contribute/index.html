CONTRIBUTE / DIGITAL FASHION LIBRARY

Donate digital patterns
and 3D fashion avatars.

Help grow the shared fashion design library with real garment patterns, graded sizes, editable pattern pieces, printable PDF/DXF files and high-detail, rigged 3D bodies suitable for fitting and animation research. Only original or legally redistributable files can be proposed.

01 / PRIORITY CONTRIBUTIONS

Digital sewing patterns

Complete, editable 1:1 garment patterns with sizes, grainlines, notches, seam allowances and expected measurements. Formats include DXF, SVG and printable PDF where authorized.

02 / CHARACTER LIBRARY

High-quality 3D avatars

Rights-cleared full-body figures with precise body dimensions, clean mesh topology, usable UV/materials, skinning and optional walking or fitting poses.

Propose an avatar donation ↗

This prepares a review proposal, not a file upload. Donating does not guarantee acceptance or commercial distribution.

NEW / COMMUNITY NATIVE-ASSET LIBRARY

Help build the small things
every designer uses.

We want an open, reusable collection of accurate 3D garment components: zippers, buttons, buckles, eyelets, snaps and more. Instead of asking every designer to model the same details, we're inviting original, rights-cleared contributions for future inclusion in ClothCraft Studio.

01 / 3D MODELS

Donate hardware

01 / WHAT THE PROJECT NEEDS

Useful examples are as valuable as code.

Real patterns, measurements and receiving reports reveal problems that synthetic demos cannot. Send only assets you own or are permitted to contribute; remove customer and factory confidentiality first.

01 / CONTRIBUTOR REQUEST

Pattern and grading source data

Share original, rights-cleared pattern pieces with measurements, curve rules, sizes, notches, grainline, seam allowances and a known expected contour result.

02 / CONTRIBUTOR REQUEST

Manufacturing / factory files

Contribute permitted DXF/AAMA/ASTM/HPGL/SVG/PDF examples, layer conventions, cutter constraints, rejected import logs and documented receiving requirements.

03 / CONTRIBUTOR REQUEST

Tech packs and BOM samples

Donate anonymized technical design flats, measurement sheets, graded POM tables, assembly callouts, stitch specs and bill-of-materials structures.

04 / CONTRIBUTOR REQUEST

Measured fabrics

Provide fabric weight, thickness, stretch, recovery, bending data, drape observations and permission for research reuse.

05 / CONTRIBUTOR REQUEST

Engineering and code

Help with Rust conversion, geometric kernels, file interoperability, native Mac builds, renderers, automation tests, profiling and CI.

06 / CONTRIBUTOR REQUEST

Validation and user testing

Reproduce editing, save/reopen, size grading, fit and export problems with versioned, nonconfidential test cases.

02 / SAFE DONATION WORKFLOW

Before you upload anything.

01 / PERMISSION

Check rights

Only share designs and data you created or that your license explicitly permits. Do not send client tech packs, confidential grading rules, private measurements or proprietary factory samples.

02 / MINIMIZE

Prepare a small test

Remove identifying information. Include units, application version, expected behavior and observed behavior; small reproducible examples are easier to test.

03 / SUBMISSION

Start a private discussion

First open an issue describing your proposed contribution and licensing constraints, without attaching sensitive source files. A maintainable upload and consent process must be agreed before transferring large datasets.
