08 / FREQUENT QUESTIONS

Open tools.
Clear answers.

Here's where the project stands, and how you can explore it today.

Is ClothCraft open source?+

The official ClothCraft repository licenses its original project source under the MIT License. Third-party libraries and assets have their own licensing terms; check the repository notices.

Is ClothCraft a complete replacement for CLO3D?+

No. ClothCraft is actively developed, and its garment solver, fitting and several production workflows remain experimental. It isn't certified as a feature-for-feature replacement.

Can I download ClothCraft?+

Visit our Download page to check whether official macOS or Windows installers have been released. No public installers are published yet; the source is freely available and can be run using the README instructions.

How much can open-source software save?+

That depends on your existing subscriptions, workflow needs, training, hardware and hosting. Use the illustrative calculator above to model your own subscription spending rather than assuming fixed savings.

How do I contribute?+

Explore the code, documentation and issues on GitHub. Patternmakers, developers, designers and testers can all help improve the project.
