BEFORE REPORTING

A great bug report helps everyone.

01

Describe expected behavior

Include the workflow you were trying to complete and what you expected.

02

Attach a reproducible example

Provide steps, platform, app version, screenshots and data that can be shared.

03

Keep your data safe

Remove private information, keys and non-redistributable garments before posting.

04 / GET UNSTUCK

A more useful path to troubleshooting.

ClothCraft is experimental. These checks can reduce the time needed to reproduce and fix a problem.

01 / CLOTHCRAFT

Before installing

Verify the build platform, release provenance, operating-system compatibility and any signing instructions. Development assets may not work on every machine.

02 / CLOTHCRAFT

If a project will not reopen

Save a copy of the original file. Record the format, app revision, file history, error output and precise action that fails.

03 / CLOTHCRAFT

If an import changes geometry

Check units, layer types, spline interpretation, contour orientation, duplicate points and whether the original source can be reopened independently.

04 / CLOTHCRAFT

If a simulation looks wrong

Share fabric parameters, solver settings, garment complexity, frame count and whether the issue repeats after reopening.

05 / CLOTHCRAFT

If grading differs by size

Provide anonymized rule data and measurable dimensions for base and affected sizes, with expected-versus-actual values.

06 / CLOTHCRAFT

If a production export fails QA

Attach a rights-cleared minimal sample, expected contour inventory and receiving tool report. Do not share a factory’s confidential pattern without permission.

05 / HELP THE PROJECT

Your experience can move development forward.

The team particularly needs pattern data, manufacturing acceptance cases, physical measurements and reproducible bug reports.

01 / CLOTHCRAFT

Share a test case

Contribute the smallest safe, licensed pattern or project demonstrating a bug or edge case.

02 / CLOTHCRAFT

Write a clear workflow

Record what task you attempted, what tools you used, what result you expected and how you checked it.

03 / CLOTHCRAFT

Join a validation effort

Review grading across sizes, factory receiving, seam-length checks or physical sample comparison.

04 / CLOTHCRAFT

Request improvements

Write an idea with the intended user, why it matters and acceptance criteria; community discussion can shape a future implementation.
