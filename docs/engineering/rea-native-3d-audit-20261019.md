# ClothCraft native, 3D, and production workflow audit — 2026-10-19

## Scope and evidence standard

Source inspection of the local EXO ClothCraft V2 workspace, Rust session bridge, C++ alternate solver, application state, browser project library, and existing QA. **Implemented in source** means a reachable code path exists; **tested in source** means an existing automated assertion covers it; neither establishes a validated CLO3D-equivalent user workflow. No native garment, Board, installed application, simulation process, or exported user data was modified during this audit. `morluto/rea` is an external research candidate, not evidence that its algorithms are integrated or compatible here.

The runtime authority is a persistent upstream Rust `exo-session` executable spawned by `integrations/clothcraft/workspace.mjs:65-105`; the repository-local Rust crates implement particular geometry/sewing/fabric utilities, while the `native_cpp` solver is a distinct incomplete alternative. As the upstream executable source and precise pinned revision were not present in this inspection, its internal collision, seam, and material mathematics **cannot be certified from local wrapper code alone**.

## `morluto/rea` research integration approach

Preserve `https://github.com/morluto/rea` as a tracked comparative source for **algorithmic and UI research**, pending repository contents, commit pin, license, and API audit. Compare its treatment of 2D editable pattern primitives, 3D assembly, physical material parameterization, mesh topology, solver, collision, serialized document and roundtrip export against the contracts above. A repo name/link alone does not establish that it recreates CLO3D, offers applicable source, or permits reuse. Do not transplant code before confirming provenance, dependencies, and compatibility. Favor a focused proof-of-concept behind an isolated adapter and a fixture measuring contour, seam, solver and export parity.

## Suggested acceptance harness

Use disposable native save roots and rerouted `POST /workspace`; capture origin revisions and read-only installed project hash. For each fixture record the full command sequence, source UI visuals, physical seam gap, penetrations, cloth normals, collisions, mesh boundary and persisted state. At every phase compare browser paper SVG cutline and underlying native Rust contour/triangle border; reject tests relying only on yellow guide curve or UI text. Export the saved pose and pattern to independent viewers, reopen, and compare dimensions in millimeters. Keep outputs small (JSON metrics, selected screenshots and compressed short visual samples) until disk is expanded.

## Limitations

This is a **static source audit**, not a fresh simulation performance run, interactive render inspection, export roundtrip or independent reimplementation of CLO3D. Exact Rust upstream collision/solver internals, full exported asset validity and `morluto/rea` contents were not reviewed here. Current code/test presence must not be represented as complete feature equivalence. Biggest immediate proof gap is a deterministic, saved, end-to-end native 2D edit → 3D sewn drape → production export roundtrip with measured physical invariants.
