# ClothCraft V2: 2D CAD source audit and REA integration priorities

Date: 2026-10-19. Scope: live working-tree **source inspection**, without changing editor or native garment data. Source lines reflect concurrent work in progress; this report is not a runtime validation certificate. Comparison target is practical CLO-style pattern authoring, with `morluto/rea` proposed as an additional reference. ## Confirmed design limits and unverified operational gaps

1. **P0: mesh/outline/transaction agreement.** A preview can intentionally precede a committed Rust mesh (`ClothCraftBoardV2.jsx:1089-1118,1777-1794`). Gate acceptance on three geometries agreeing: dragged paper fill, committed cutline edge polyline and compiled mesh boundary. Exercise side-left/right on front/back, mouse pointer capture/cancel, seam-ease staged Apply, native save/reopen, and unchanged revision after cancel. Read back the real native contour; a yellow stroke alone is insufficient.
2. **P0: hit-target and event routing.** Transparent station circles (`ClothCraftBoardV2.jsx:2158-2177`), cutline hit targets (`:1917-1971`), guide interception (`:694-752`), surface pointer handler (`:1789-1796`) and document drag state (`:1150-1275`) overlap. Use `elementFromPoint` plus pointer event target/currentTarget/capture traces at each station; then verify full drag, not only pointerdown. If cutline intercepts a station, adjust narrow hit target/stacking and add one QA assertion. Preserve existing edge-selection behavior.
3. **P0: sewing topology and easing.** `Shape` submission and seam-easing proposal are distinct operations (`:1089-1118`). Tests must prove symmetric moving controls preserve named edges, seam IDs, notch locations and allowances, with explicit easing only for affected pairs; undo/redo and reopen must reproduce the exact geometry. Avoid silently lengthening paired seams through guide offsets.
4. **P0: canonical provenance.** Browser-persisted guide half-curves (`:581-600`) are not project-native data. Adopt a typed persisted construction-line model with stable IDs, dependencies, guide constraints and revisioning if guides are intended to drive patterns across machines; until then visibly label them construction-only.
5. **P1: symmetry semantics.** The axis based on min/max x (`nativeFreeCurvePoints.js:152-170`) may drift for asymmetric pieces; the same-edge symmetric case is excluded from free-knot tangent pairing (`:258-263`). Provide a persisted piece symmetry axis and deterministic source/peer mappings, including self-symmetric hem, left/right sides, unequal seam allowance profiles, and transformed/rotated layout.
6. **P1: curve constraints and numerical input.** The exposed controls are drag/keyboard modifiers (`nativeFreeCurvePoints.js:230-274`, `ClothCraftBoardV2.jsx:1540-1547`). A factory editor needs exact knot x/y, tangent angle and magnitude, radius-like constraints where applicable, offset/perimeter targets, point/line locking and an explicit unit-aware inspector. Use the Rust contour as the measurement authority and define a tolerance budget.
7. **P1: contour station robustness.** `sideCurveStation` uses 128 samples and local 25-step bisection then chooses a crossing (`patternCurveDrafting.js:10-37`). For double-back curves, ask the user to select a branch or retain a physical edge station identity through edits; test tangencies and zero-crossing cases. Replace heuristic chest/belly station fractions with named measurement/dependency definitions.
8. **P1: industrial measurement.** Current POM drawing uses Euclidean separation between edge anchors (`ClothCraftBoardV2.jsx:2549-2558`); add measurement pathways (straight, along-boundary, between notches, around sewn circumference), label/tolerance and size, reference state (flat vs sewn), and exportable measurement chart with revision and unit control. Validate against independently measured fixtures.
9. **P1: real darts, pleats and grading.** Red ticks are visual-only (`ClothCraftBoardV2.jsx:2180-2206`). Build authorable dart apex, legs, intake and fold closure that alters 2D sewn geometry and 3D assembly; then pleat folding and grading rules bound to stable vertices. Existing toolbar coverage audit identifies historic unavailable workflow slots (`docs/engineering/2d-tool-coverage-20261018.md:5-15,21-31`); recheck current source before declaring an entry absent.
10. **P1: production exchange.** Display offsets are not authoritative allowance contours (`patternAllowancePreview.js:2-6`). Implement per-edge allowance corner behavior, cut/stitch lines, grainline, internal marks, notches/drill holes, label placement, true-scale print and DXF/AAMA/ASTM import/export round trips with millimetre-level geometry checks.
11. **P2: workflow completeness.** Trace/reference drafting, walk pattern with paired seam-length visualization, pivot/rotate points, true internal polygons/curves, multi-piece duplication, sizing, grading and reusable block templates need one coherent action model with operation history. Verify every visible button with a command and persistence acceptance case before advertising CLO parity.

## Minimal acceptance fixture matrix

| Fixture | Action | Required evidence |
| --- | --- | --- |
| Front/back × left/right side | Add station knot, drag 10–20 mm, cancel, then redo and commit | During drag paper `d` changes, cancel preserves revision, commit changes Rust boundary and survives reopen; no unwanted second knot |
| Strict sewn side seam | Drag spline then explicitly Apply seam easing | Native `Shape` rebuild, seam `allow_ease` and IDs read back; seam length diagnostics explain actual mismatch |
| Mirrored hem and sides | Drag source cubic handle and free knot | Reflected peer controls around persisted axis with consistent tangent orientation; no unpaired over-application |
| Concave/double-back side | Select intermediate/belly station | Deterministic intended crossing and material position after curve reshape |
| POM + allowance + notches | Create, rename, change adjacent edge, save/reopen/export | Stable measurement endpoints and units, correct notch/allowance positions, production reader validates cutline |
| Real dart and size grading | Open/close dart; grade across three sizes | Cutline/seam topology, geometry deltas, 3D seam assembly and exported factory pattern remain aligned |

## REA reference investigation

Inspect `https://github.com/morluto/rea` in a separate, version-pinned and license-reviewed read-only checkout before any code reuse. Record commit SHA, licensing for code/assets, CAD data model, curve/kernel representation, constraints and snapping, selection/event flow, persistence/export format and test corpus. Compare REA functions one by one with ClothCraft's native Rust authority; borrow architecture and reproducible tests where lawful and useful. The present audit cannot substantiate claims about REA internals because that repository was not fetched or read here.
